## 建议验收

1. 安装最新版，只保留一个 Mining 页面和一份启用脚本。
2. 点击开始，观察页面自动滚动并定位 Greenstone Quarry。
3. 能量充足时确认每次部署后任务数增加，再次部署有停顿。
4. 能量不足时确认面板按 N 分钟计时，弹窗关闭。
5. 多个奖励就绪时观察一次只领取一个，前一个页面状态变化后再领取下一个。
6. 手动更新等待时间，确认当前倒计时改变。
7. 点击停止，确认后续点击停止；刷新后仍停止。

测试中的部署会消耗账户能量。故障恢复测试应在理解可能重复尝试部署的情况下进行。不要把语法检查当成页面功能验证。
